# 使用示例

以下示例假设：

```bash
PY="C:/Users/yt947/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
SKILL="<本 skill 目录>/scripts"
```

## 示例 1：从零开始，只有任务名称和工期

用户说：「帮我排个装修工程进度，拆改 5 天、水电 8 天、贴砖 6 天、油漆 5 天、安装 4 天，串着来，从 3 月 2 日开始。」

先落成 CSV：

```csv
WBS,任务名称,类型,工期,前置任务,负责人
1,拆改工程,任务,5,,施工队
2,水电改造,任务,8,1,水电组
3,贴砖工程,任务,6,2,瓦工组
4,油漆工程,任务,5,3,油漆组
5,安装收尾,任务,4,4,安装组
6,竣工验收,里程碑,0,5,项目部
```

生成：

```bash
"$PY" "$SKILL/build.py" 装修进度.csv -o 装修进度.html --png 装修进度.png \
  --name "某住宅装修工程进度计划" --start 2026-03-02
```

结果：任务日期自动按依赖推导并跳过周末（3/7、3/8 不排期）。

## 示例 2：关键节点跟踪（里程碑）

用户：「项目有 5 个必须守住的节点：需求冻结、设计评审、测试报告、上线、验收。」

把节点行设为 `里程碑` 类型：

```csv
WBS,任务名称,类型,开始日期,前置任务,备注
1.2,需求冻结,里程碑,2026-03-16,1.1,需求基线冻结
2.3,设计评审,里程碑,2026-04-09,2.2,技术方案定稿
4.3,测试报告,里程碑,2026-07-13,4.2,提测结论输出
5.3,正式上线,里程碑,2026-08-24,5.2,系统切换生产
5.4,项目验收,里程碑,2026-08-25,5.3,验收签字
```

生成后节点以橙色菱形呈现，并纳入关键路径计算。
若设为关键路径，菱形会加红色描边。

## 示例 3：搭接施工（SS 关系）

用户：「管道预埋不用等基础开挖全部结束，开挖 3 天后就能进场。」

```csv
WBS,任务名称,类型,工期,前置任务
2.1,基础开挖,任务,8,
2.2,管道预埋,任务,10,2.1:SS:3
```

`SS:3` 表示管道预埋从基础开挖开始 3 个工作日后启动，两者搭接。

## 示例 6：自定义节假日

```bash
"$PY" "$SKILL/build.py" tasks.csv -o out.html \
  --start 2026-09-25 \
  --holidays "2026-10-01,2026-10-02,2026-10-05,2026-10-06,2026-10-07"
```

国庆假期不排期，工期自动顺延。

## 示例 7：改为自然日日历

适用于需要连续作业的工程（不停工）：

```bash
"$PY" "$SKILL/build.py" tasks.csv -o out.html --calendar natural
```

此时周末也计入工期，不再跳过。

## 示例 9：在 HTML 中编辑与调整

生成的 HTML 支持完整编辑，无需重新跑脚本：

**方式一：双击编辑（推荐）**
1. 打开 HTML
2. **双击**任意任务条 / 左侧任务行 / 右侧行空白处 → 弹出编辑窗口
3. 可修改：任务名称、类型（普通任务 ↔ 里程碑）、开始/结束日期（与工期联动）、完成进度、负责人、备注、前置依赖（可增删，FS/SS/FF/SF + 滞后天数）
4. 点「保存并重排」→ 后续任务自动按依赖顺延
5. 工具栏「＋ 添加任务」→ 新建任务；编辑窗口内「删除任务」→ 删除叶子任务（自动清理依赖）

**方式二：拖拽快速改期**
1. 拖动任务条左右移动 → 日期改变
2. 拖动任务条最右端 → 改工期
3. 松手后，其后续任务按依赖自动顺延

**通用**
- 点「按依赖重排」可全量重算
- 点「? 操作说明」查看全部交互指引
- 点「导出 PNG」保存当前视图

适合会议中现场调整进度方案。固化修改：把调整结果告诉 AI 更新源数据，或直接改 CSV/Excel 后重新构建。

## 常见问题

**Q：任务日期没按依赖走？**
检查「前置任务」列引用的 WBS / 编号 / 名称是否与任务行完全一致，且依赖没有形成闭环（A→B→A）。

**Q：工期看起来比预期大？**
默认按工作日计，跨周末会拉长日历跨度。`3-02 ~ 3-13` 显示 10 天（工作日），
日历上占 12 天。若要按自然日，加 `--calendar natural`。

**Q：里程碑为什么没有工期？**
里程碑是零工期事件，强制 `duration = 0`，这是设计行为。

**Q：中文在 PNG 里显示成方框？**
系统缺少中文字体。安装「微软雅黑」或「思源黑体」后重试；
脚本会自动探测 `Microsoft YaHei / SimHei / PingFang SC` 等字体。

**Q：任务顺序和输入不一致？**
摘要任务的起止由子任务汇总，可能与手填值不同；
按 WBS 组织数据可获得最稳定的层级与顺序。
